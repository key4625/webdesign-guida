Introduzione e poster

Flexbox (Flexible Box Layout) è il sistema per disporre elementi in una dimensione: in riga oppure in colonna. Decide come distribuire lo spazio, come allineare e in che ordine mostrare gli elementi, anche quando non conosci in anticipo le loro dimensioni.

Ci sono sempre due attori:

  • il contenitore (flex container): l'elemento a cui scrivi display: flex;
  • gli elementi (flex items): i suoi figli diretti, e solo quelli.

Il poster qui accanto, realizzato da CSS-Tricks, riassume tutte le proprietà in un colpo d'occhio: la colonna di sinistra e quella centrale riguardano il contenitore (etichette viola), quella di destra gli elementi (etichette arancioni). Questa pagina lo segue punto per punto.

Clicca sul poster per aprirlo a piena risoluzione: è perfetto da stampare o da tenere aperto in un'altra scheda mentre lavori.

Il concetto chiave: i due assi

Se capisci gli assi, capisci Flexbox. Non si parla di "orizzontale" e "verticale", ma di:

  • Asse principale (main axis): la direzione in cui gli elementi si mettono in fila. Lo comanda justify-content.
  • Asse trasversale (cross axis): perpendicolare al principale. Lo comanda align-items.

■ asse principale (justify-content) · ■ asse trasversale (align-items)

Il dubbio più frequente: "ho messo justify-content: center ma non si centra in verticale!". Con flex-direction: column gli assi si scambiano: justify-content lavora in verticale e align-items in orizzontale.

Proprietà del contenitore

display: flex | inline-flex

Attiva Flexbox. Con flex il contenitore si comporta da blocco (va a capo, occupa tutta la riga); con inline-flex sta in linea con il testo, largo quanto il contenuto.

flex-direction

Stabilisce l'asse principale, cioè in che direzione si mettono in fila gli elementi.

.container {
    flex-direction: row;            /* → default */
    flex-direction: row-reverse;    /* ← */
    flex-direction: column;         /* ↓ */
    flex-direction: column-reverse; /* ↑ */
}

flex-wrap e flex-flow

Di default (nowrap) gli elementi restano tutti su una riga, restringendosi o sbordando. Con wrap vanno a capo quando non c'è più spazio.

.container {
    flex-wrap: nowrap;        /* default: tutto su una riga */
    flex-wrap: wrap;          /* va a capo verso il basso */
    flex-wrap: wrap-reverse;  /* va a capo verso l'alto */

    /* Shorthand: direction + wrap */
    flex-flow: row wrap;
}

gap, row-gap, column-gap

Lo spazio tra gli elementi (non ai bordi). Sostituisce i vecchi margini sugli elementi, che lasciavano spazio in più sull'ultimo.

.container {
    gap: 1rem;            /* righe e colonne */
    gap: 1rem 2rem;       /* row-gap column-gap */
    row-gap: 1rem;
    column-gap: 2rem;
}

Proprietà degli elementi

Cambia l'ordine visivo senza toccare l'HTML. Il default è 0; valori più bassi vanno prima, anche negativi.

flex-grow: chi prende lo spazio in più

Quando nel contenitore avanza spazio, flex-grow dice in che proporzione distribuirlo. Default 0: nessuno cresce.

tutti flex-grow: 1 → lo spazio libero è diviso in parti uguali

Attenzione: flex-grow: 2 non significa "largo il doppio", ma "riceve il doppio dello spazio avanzato". Per larghezze proporzionali esatte serve anche flex-basis: 0 (vedi flex: 1 più sotto).

flex-shrink: chi cede quando manca spazio

L'opposto: quando lo spazio non basta, in che proporzione gli elementi si restringono. Default 1: tutti si restringono allo stesso modo. Con 0 un elemento si rifiuta di stringersi (utile per loghi, icone, avatar).

.avatar {
    flex-shrink: 0;   /* L'immagine del profilo non si schiaccia mai */
    width: 48px;
}

flex-basis: la dimensione di partenza

La dimensione "ideale" dell'elemento lungo l'asse principale, prima che entrino in gioco grow e shrink. Con row è come una width, con column come una height. Default auto: usa la width o la dimensione del contenuto.

Il trucco di margin: auto

In un contenitore flex un margine auto assorbe tutto lo spazio libero in quella direzione. È il modo più semplice per spingere un elemento dall'altra parte: il classico menu con il bottone "Accedi" a destra.

.navbar {
    display: flex;
    align-items: center;
    gap: 1rem;
}

.navbar .login {
    margin-left: auto;   /* Spinge sé stesso (e quelli dopo) tutto a destra */
}

Pattern pratici

Media object (immagine + testo)

.commento {
    display: flex;
    gap: 1rem;
    align-items: flex-start;
}
.commento img {
    flex-shrink: 0;
    width: 48px;
    border-radius: 50%;
}

Sidebar fissa + contenuto fluido

.layout {
    display: flex;
    gap: 2rem;
}
.layout aside { flex: 0 0 250px; }
.layout main  { flex: 1; min-width: 0; }

Card che vanno a capo

.cards {
    display: flex;
    flex-wrap: wrap;
    gap: 1rem;
}
.cards .card {
    flex: 1 1 250px; /* min ~250px, poi crescono */
}

Menu mobile → desktop

.menu {
    display: flex;
    flex-direction: column;  /* mobile: in colonna */
    gap: 0.5rem;
}
@media (min-width: 768px) {
    .menu { flex-direction: row; }
}

Altri pattern (centratura, footer in fondo, card con bottone allineato) sono nella pagina Problemi di tutti i giorni.

Errori comuni

  • display: flex sull'elemento sbagliato. Va sul genitore degli elementi da disporre, non sugli elementi stessi.
  • Flexbox agisce solo sui figli diretti. I nipoti non sono flex items: se servono, il figlio deve diventare a sua volta display: flex.
  • Assi confusi con column. justify-content lavora sempre sull'asse principale, qualunque esso sia.
  • align-items: center non fa niente. Il contenitore non ha altezza: è alto quanto gli elementi, quindi non c'è spazio da distribuire.
  • align-content non fa niente. Manca flex-wrap: wrap: con una sola riga non ha effetto.
  • Un elemento sborda e non si restringe. Aggiungi min-width: 0 all'elemento flex (vedi Problemi di tutti i giorni).
  • Usare Flexbox per una griglia a due dimensioni. Se vuoi righe e colonne allineate tra loro, è un lavoro per CSS Grid.
