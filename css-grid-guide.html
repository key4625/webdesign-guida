Introduzione e poster

CSS Grid è il sistema di layout a due dimensioni: controlli righe e colonne contemporaneamente. Disegni prima la griglia sul contenitore, poi decidi dove va ogni elemento, anche su più celle o sovrapposto ad altri.

Come in Flexbox ci sono un contenitore (display: grid) e i suoi figli diretti, gli elementi della griglia.

Il poster di CSS-Tricks raccoglie tutto in una pagina: colonne sinistra e centrale con le proprietà del contenitore, colonna destra con quelle degli elementi. Nei diagrammi i numeri tra parentesi quadre ([1], [-1]...) sono i numeri di linea: tienili d'occhio, sono la chiave di tutto.

Clicca sul poster per aprirlo a piena risoluzione.

Il vocabolario di Grid

LineaLe "righe di matita" che dividono la griglia. Si contano da 1 (non da 0!) e anche al contrario, da -1 (l'ultima). Con 3 colonne ci sono 4 linee verticali.
Traccia (track)Lo spazio tra due linee adiacenti: una colonna o una riga.
CellaL'incrocio tra una riga e una colonna: l'unità più piccola.
AreaUn rettangolo di più celle, delimitato da quattro linee.
GapLo spazio tra le tracce (il "canale" tra righe e colonne).

Definire righe e colonne

grid-template-columns e grid-template-rows elencano le dimensioni delle tracce, separate da spazi: ogni valore è una colonna (o riga).

.container {
    display: grid;

    grid-template-columns: 200px 200px 200px;   /* 3 colonne fisse */
    grid-template-columns: 1fr 1fr 1fr;         /* 3 colonne uguali */
    grid-template-columns: repeat(3, 1fr);      /* Uguale, più corto */
    grid-template-columns: 250px 1fr;           /* Sidebar fissa + contenuto fluido */
    grid-template-columns: 1fr 2fr 1fr;         /* La centrale è doppia */
    grid-template-columns: auto 1fr auto;       /* Laterali grandi quanto il contenuto */
    grid-template-columns: minmax(200px, 1fr) 3fr; /* Mai sotto 200px */

    grid-template-rows: 80px auto 60px;         /* header, contenuto, footer */
}

L'unità fr

fr sta per fraction: una parte dello spazio rimasto libero dopo aver tolto le tracce fisse e i gap. In 250px 1fr 2fr il browser toglie 250px, divide il resto in 3 parti, ne dà 1 alla seconda colonna e 2 alla terza.

Dare un nome alle linee

Nel poster vedi [row1-start], [last-line]: tra parentesi quadre si possono dare nomi alle linee, per poi usarli al posto dei numeri.

.container {
    grid-template-columns: [inizio] 250px [contenuto] 1fr [fine];
}
.banner {
    grid-column: contenuto / fine;
}

auto-fit e auto-fill: griglie che si adattano da sole

Invece di un numero fisso di colonne, repeat() può calcolare quante ne entrano. Unito a minmax() crea una griglia responsive senza nessuna media query.

.galleria {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
    /* "Crea tutte le colonne che entrano, larghe almeno 200px,
        poi dividi equamente lo spazio rimasto" */
}

La differenza tra le due parole chiave si vede solo quando gli elementi sono pochi e avanza spazio:

auto-fit → le colonne vuote collassano, gli elementi si allargano

Regola pratica: auto-fit per card e gallerie che devono riempire la riga; auto-fill quando vuoi che gli elementi abbiano sempre la stessa larghezza, anche se sono solo due. Per non sbordare su schermi minuscoli scrivi minmax(min(200px, 100%), 1fr).

grid-template-areas: disegnare il layout

Il modo più visivo di usare Grid: scrivi una "mappa" del layout con dei nomi. Ogni stringa è una riga, ogni parola una colonna, il punto . è una cella vuota. Ripetere un nome su più celle crea un'area più grande (deve restare un rettangolo).

.pagina {
    display: grid;
    grid-template-columns: 1fr 1fr 1fr 1fr;
    grid-template-areas:
        "header header  header  header"
        "main   main    .       sidebar"
        "footer footer  footer  footer";
}
.pagina header { grid-area: header; }
.pagina main   { grid-area: main; }
.pagina aside  { grid-area: sidebar; }
.pagina footer { grid-area: footer; }

Posizionare gli elementi

Di default ogni elemento occupa la cella libera successiva. Con grid-column e grid-row dici invece da quale linea a quale linea deve estendersi.

.item {
    grid-column: 1 / 3;      /* Dalla linea 1 alla linea 3 = 2 colonne */
    grid-column: 1 / -1;     /* Dalla prima all'ultima: tutta la larghezza */
    grid-column: span 2;     /* Occupa 2 colonne, a partire da dove capita */
    grid-column: 2 / span 3; /* Parte dalla linea 2 e occupa 3 colonne */

    grid-row: 1 / 3;         /* Due righe */

    /* Shorthand: row-start / column-start / row-end / column-end */
    grid-area: 1 / 2 / 3 / 4;
}

Griglia esplicita e implicita

Se definisci 3 colonne e 2 righe ma inserisci 10 elementi, Grid non va in crisi: crea automaticamente le righe che mancano. Queste sono la griglia implicita, e la loro dimensione si controlla con grid-auto-rows.

.galleria {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    grid-auto-rows: 200px;               /* Ogni nuova riga è alta 200px */
    grid-auto-rows: minmax(150px, auto); /* Almeno 150px, di più se serve */

    grid-auto-flow: row;     /* Default: riempie riga per riga */
    grid-auto-flow: column;  /* Riempie colonna per colonna */
    grid-auto-flow: dense;   /* Riempie i "buchi" lasciati dagli elementi grandi */
}

dense è perfetto per gallerie di foto con elementi di dimensioni diverse (stile masonry), ma cambia l'ordine visivo rispetto all'HTML: come per order, attenzione all'accessibilità. Provalo nel playground qui sopra con repeat(3, 1fr).

Grid o Flexbox?

Non sono in competizione: si usano insieme, spesso Grid per la struttura della pagina e Flexbox per i componenti al suo interno.

FlexboxGrid
DimensioniUna (riga o colonna)Due (righe e colonne)
ApproccioDal contenuto: gli elementi decidono quanto spazio occupareDal layout: disegni la griglia, poi ci metti gli elementi
Allineamento tra righeOgni riga è indipendenteLe colonne restano allineate su tutte le righe
Ideale perNavbar, gruppi di bottoni, media object, centrareLayout di pagina, gallerie, dashboard, card in griglia
Test rapido: se in una griglia di card con flex-wrap l'ultima riga ha elementi più larghi delle altre e la cosa ti dà fastidio, ti serve Grid.

Pattern pratici

Testo sopra un'immagine (sovrapposizione nella stessa cella)

Con Grid più elementi possono occupare la stessa cella: si sovrappongono senza bisogno di position: absolute.

.hero {
    display: grid;
}
.hero > * {
    grid-area: 1 / 1;   /* Tutti nella cella 1,1 */
}
.hero .testo {
    align-self: end;    /* Il testo in basso */
}

Contenuto centrato con fasce a tutta larghezza

Le colonne laterali "elastiche" tengono il testo a una larghezza leggibile, ma un'immagine può uscire e occupare tutto lo schermo.

.articolo {
    display: grid;
    grid-template-columns: 1fr min(65ch, 100% - 2rem) 1fr;
}
.articolo > *      { grid-column: 2; }      /* Tutto nella colonna centrale */
.articolo > .larga { grid-column: 1 / -1; } /* Questa da bordo a bordo */

Dashboard con aree

.dashboard {
    display: grid;
    grid-template-columns: 220px repeat(3, 1fr);
    grid-template-rows: auto 1fr 1fr;
    grid-template-areas:
        "menu top    top    top"
        "menu grafico grafico kpi"
        "menu tabella tabella tabella";
    gap: 1rem;
    min-height: 100dvh;
}

Per allineare elementi dentro card diverse (titoli, testi e bottoni tutti alla stessa altezza) esiste subgrid: vedi CSS Moderno → Layout.
