Introduzione a CSS

CSS (Cascading Style Sheets) è il linguaggio usato per definire lo stile e il layout delle pagine web.

Come Includere CSS

1. CSS Esterno (Consigliato)
<link href="style.css" 
      rel="stylesheet">
2. CSS Interno
<style>
  p { color: blue; }
</style>
3. CSS Inline
<p style="color:blue">
  Testo
</p>

Selettori CSS

I selettori determinano quali elementi HTML vengono stilizzati:

Selettore Sintassi Descrizione Esempio
Universale * Seleziona tutti gli elementi * { margin: 0; }
Elemento elemento Seleziona elementi per tipo p { color: red; }
Classe .classe Seleziona per classe .box { width: 100px; }
ID #id Seleziona per ID univoco #header { height: 60px; }
Discendente A B B dentro A (qualsiasi livello) div p { color: blue; }
Figlio A > B B figlio diretto di A div > p { font-size: 14px; }
Fratello adiacente A + B B immediatamente dopo A h1 + p { margin-top: 0; }
Fratelli generali A ~ B Tutti i B dopo A h1 ~ p { color: gray; }
Gruppo A, B Seleziona A e B h1, h2, h3 { font-weight: bold; }

Pseudo-classi

/* Stati degli elementi */
a:hover { color: red; }          /* Al passaggio del mouse */
a:active { color: green; }        /* Durante il click */
a:visited { color: purple; }      /* Link visitato */
input:focus { border: 2px solid blue; } /* Elemento attivo */

/* Posizione nell'albero */
li:first-child { font-weight: bold; }   /* Primo figlio */
li:last-child { color: gray; }          /* Ultimo figlio */
li:nth-child(2) { color: blue; }        /* Secondo figlio */
li:nth-child(odd) { background: #f0f0f0; }  /* Figli dispari */
li:nth-child(even) { background: white; }   /* Figli pari */

/* Altri */
p:not(.special) { color: black; } /* Tutti i p tranne .special */
div:empty { display: none; }      /* Div vuoti */

Pseudo-elementi

/* Aggiungere contenuto prima/dopo */
p::before {
    content: "→ ";
    color: blue;
}

p::after {
    content: " ←";
    color: red;
}

/* Prima lettera e prima riga */
p::first-letter {
    font-size: 2em;
    font-weight: bold;
}

p::first-line {
    color: blue;
}

/* Selezione del testo */
::selection {
    background: yellow;
    color: black;
}

Selettori di Attributo

/* Elemento con attributo */
img[alt] { border: 1px solid blue; }

/* Attributo con valore esatto */
input[type="text"] { background: white; }

/* Attributo che contiene */
a[href*="google"] { color: blue; }

/* Attributo che inizia con */
a[href^="https"] { color: green; }

/* Attributo che finisce con */
img[src$=".jpg"] { border: 2px solid red; }

Cascata, Specificità ed Ereditarietà

Spesso più regole CSS colpiscono lo stesso elemento con valori diversi. Il browser decide quale vince seguendo tre meccanismi: la cascata, la specificità e l'ereditarietà. Capirli risponde alla domanda più frequente: "perché il mio stile non funziona?"

1. La Cascata: l'ordine conta

A parità di specificità, vince la regola scritta per ultima. Questo vale anche tra file diversi: conta l'ordine in cui i fogli di stile sono collegati nell'HTML.

p { color: blue; }
p { color: red; }   /* Vince questa: stessa specificità, scritta dopo */
<!-- style.css viene letto dopo bootstrap.css: a parità di specificità vince style.css -->
<link rel="stylesheet" href="bootstrap.min.css">
<link rel="stylesheet" href="style.css">

2. La Specificità: il "peso" del selettore

Ogni selettore ha un peso calcolato su tre colonne (ID, Classi, Elementi). Si confronta da sinistra a destra: un solo ID batte qualsiasi numero di classi.

Selettore ID Classi, attributi, pseudo-classi Elementi, pseudo-elementi Specificità
p 001 0-0-1
article p 002 0-0-2
.testo 010 0-1-0
p.testo:hover 021 0-2-1
.card .titolo a 021 0-2-1
#header 100 1-0-0
style="..." (inline) Batte qualsiasi selettore nel foglio di stile massima 
/* HTML: <p id="intro" class="testo">Ciao</p> */

#intro   { color: green; }  /* 1-0-0 → VINCE */
.testo   { color: red; }    /* 0-1-0 */
p        { color: blue; }   /* 0-0-1 */

/* Il selettore universale * e i combinatori (>, +, ~) valgono 0 */
Attenzione a !important: scavalca cascata e specificità, ma per batterlo serve un altro !important, e il CSS diventa presto ingestibile. Usalo solo in casi eccezionali (es. classi di utilità). Se uno stile "non prende", prima controlla la specificità.

3. L'Ereditarietà: cosa passa ai figli

Alcune proprietà si trasmettono automaticamente dagli elementi genitori ai figli, altre no.

Ereditate (soprattutto testo)
  • color
  • font-family, font-size, font-weight
  • line-height, text-align
  • letter-spacing, visibility, cursor
Non ereditate (soprattutto box)
  • margin, padding, border
  • width, height
  • background
  • display, position
/* Impostando il font sul body, tutta la pagina lo eredita */
body {
    font-family: 'Inter', sans-serif;
    color: #222;
}

/* Parole chiave per controllare l'ereditarietà */
button {
    font: inherit;      /* Eredita dal genitore (i bottoni di default non lo fanno) */
}
.reset {
    color: initial;     /* Torna al valore iniziale della specifica CSS */
    margin: unset;      /* inherit se la proprietà è ereditata, altrimenti initial */
}
a {
    color: currentColor; /* Usa il valore di color dell'elemento stesso */
}
Debug con DevTools: fai clic destro sull'elemento → Ispeziona. Nel pannello Stili le regole sono ordinate per specificità e quelle battute appaiono barrate: vedi subito quale regola vince e perché. Passando il mouse sul selettore, Chrome mostra anche la sua specificità.

Unità di Misura

Le dimensioni in CSS si esprimono con unità assolute (fisse) o relative (che dipendono da qualcos'altro: il font, il genitore, la finestra). Per un design responsive e accessibile le unità relative sono quasi sempre la scelta migliore.

Unità Relativa a Uso tipico
px Fissa (pixel CSS) Bordi, ombre, dettagli sottili
rem Font-size dell'elemento radice <html> (di default 16px) Font-size, spaziature, layout: la scelta predefinita
em Font-size dell'elemento stesso (o del genitore, se usata su font-size) Padding di bottoni e componenti che devono scalare col proprio testo
% Dimensione del genitore Larghezze fluide (width: 50%)
vw / vh 1% della larghezza / altezza della finestra Sezioni a tutto schermo, titoli fluidi
dvh / svh Altezza "reale" della finestra su mobile (con o senza barra del browser) Hero a schermo intero su smartphone
ch Larghezza del carattere "0" del font Lunghezza ottimale delle righe di testo (max-width: 65ch)
fr Frazione dello spazio libero (solo in Grid) Colonne di una griglia

em vs rem: la differenza che conta

html { font-size: 100%; }   /* = 16px, rispetta le preferenze dell'utente */

.card { font-size: 1.25rem; } /* 20px */

.card p {
    font-size: 1.5em;   /* 1.5 × 20px = 30px  → dipende dal genitore */
    font-size: 1.5rem;  /* 1.5 × 16px = 24px  → sempre uguale, prevedibile */
}

/* Con em le dimensioni si moltiplicano negli annidamenti:
   un elenco dentro un elenco dentro un elenco diventa sempre più grande */

calc(): mescolare unità diverse

.sidebar-layout main {
    width: calc(100% - 300px);       /* Tutto lo spazio meno la sidebar */
}
.hero {
    min-height: calc(100dvh - 4rem); /* Schermo intero meno la navbar */
}
Esempio - stessa scatola, unità diverse:
120px
10rem
25%
20ch

Prova a ridimensionare la finestra: solo la scatola in % cambia larghezza. Prova anche a ingrandire il testo del browser (Ctrl +): le scatole in rem e ch crescono con il testo, quella in px no.

Regola pratica: usa rem per font e spaziature, %/fr per le larghezze del layout, px solo per dettagli come bordi e ombre. Per titoli che scalano in modo fluido c'è clamp(), spiegata nella guida CSS Moderno.

Box Model

Ogni elemento HTML è una "scatola" con: contenuto, padding, border e margin.

Margin (margine esterno)
Border (bordo)
Padding (spaziatura interna)
Content (contenuto)
.box {
    /* Dimensioni */
    width: 300px;
    height: 200px;
    max-width: 100%;      /* Larghezza massima */
    min-height: 150px;    /* Altezza minima */
    
    /* Padding (spaziatura interna) */
    padding: 20px;                    /* Tutti i lati */
    padding: 10px 20px;               /* Verticale | Orizzontale */
    padding: 10px 20px 15px 25px;    /* Top | Right | Bottom | Left */
    padding-top: 10px;
    padding-right: 20px;
    padding-bottom: 15px;
    padding-left: 25px;
    
    /* Border (bordo) */
    border: 2px solid black;          /* Spessore | Stile | Colore */
    border-width: 2px;
    border-style: solid;              /* solid | dashed | dotted | double */
    border-color: black;
    border-radius: 10px;              /* Angoli arrotondati */
    border-radius: 10px 20px;         /* Top-left/Bottom-right | Top-right/Bottom-left */
    
    /* Margin (margine esterno) */
    margin: 20px;                     /* Tutti i lati */
    margin: 10px auto;                /* Verticale | Orizzontale (auto centra) */
    margin-top: 10px;
    margin-bottom: 20px;
    
    /* Box sizing */
    box-sizing: border-box;           /* Include padding e border nella width */
}
Tip: Usa box-sizing: border-box; per calcoli più intuitivi delle dimensioni. È una best practice applicarlo a tutti gli elementi con * { box-sizing: border-box; }

content-box vs border-box

.box {
    width: 300px;
    padding: 20px;
    border: 5px solid;
}
/* content-box (default):  larghezza reale = 300 + 20×2 + 5×2 = 350px  😕 */
/* border-box:             larghezza reale = 300px, il contenuto si restringe  ✅ */

Reset: un punto di partenza pulito

Ogni browser applica stili predefiniti (margini sui titoli, padding sulle liste, immagini inline...). Un piccolo reset all'inizio del foglio di stile rende il comportamento prevedibile. Questo è un reset moderno e minimo:

/* 1. Box model intuitivo per tutto */
*, *::before, *::after {
    box-sizing: border-box;
}

/* 2. Niente margini predefiniti */
* {
    margin: 0;
}

/* 3. Testo leggibile e altezza minima della pagina */
body {
    min-height: 100dvh;
    line-height: 1.5;
    -webkit-font-smoothing: antialiased;
}

/* 4. Media che non escono mai dal contenitore */
img, picture, video, canvas, svg {
    display: block;
    max-width: 100%;
}

/* 5. I campi dei form ereditano il font della pagina */
input, button, textarea, select {
    font: inherit;
}

/* 6. Le parole lunghe vanno a capo invece di uscire dal box */
p, h1, h2, h3, h4, h5, h6 {
    overflow-wrap: break-word;
}
Nota: framework come Bootstrap includono già il proprio reset (Reboot). Se usi Bootstrap non serve aggiungerne un altro.

Display e Posizionamento

Display

.elemento {
    display: block;        /* Occupa tutta la larghezza, va a capo */
    display: inline;       /* Occupa solo lo spazio necessario, sulla stessa linea */
    display: inline-block; /* Come inline ma accetta width/height */
    display: flex;         /* Contenitore flessibile (vedi Flexbox) */
    display: grid;         /* Griglia (vedi CSS Grid) */
    display: none;         /* Nasconde l'elemento */
}

Position

Valore Descrizione Esempio
static Posizionamento normale (default) position: static;
relative Relativo alla posizione normale position: relative; top: 10px;
absolute Relativo al parent più vicino con position position: absolute; top: 0; left: 0;
fixed Fisso rispetto alla finestra del browser position: fixed; bottom: 20px;
sticky Fisso quando raggiungi una posizione di scroll position: sticky; top: 0; 
/* Centrare con position absolute */
.centrato {
    position: absolute;
    top: 50%;
    left: 50%;
    transform: translate(-50%, -50%);
}

/* Z-index (ordine di sovrapposizione) */
.sopra {
    position: relative;
    z-index: 10;
}

/* Overflow (gestione contenuto che eccede) */
.container {
    overflow: auto;     /* Mostra scrollbar se necessario */
    overflow: hidden;   /* Nasconde contenuto eccedente */
    overflow: scroll;   /* Mostra sempre scrollbar */
    overflow-x: auto;   /* Solo orizzontale */
    overflow-y: auto;   /* Solo verticale */
}

z-index e Contesto di Sovrapposizione (Stacking Context)

z-index decide chi sta "sopra" quando gli elementi si sovrappongono, ma ha due regole che confondono spesso:

  1. Funziona solo su elementi posizionati (position diverso da static) oppure figli di flex/grid.
  2. Il confronto avviene solo tra elementi dello stesso contesto. Alcune proprietà creano un nuovo contesto "chiuso": un figlio con z-index: 9999 non può uscire dal contesto del suo genitore.
/* Proprietà che creano un nuovo stacking context */
.contesto {
    position: relative; z-index: 1;  /* position + z-index */
    opacity: 0.99;                   /* opacity minore di 1 */
    transform: translateX(0);        /* qualsiasi transform */
    filter: blur(0);                 /* filter, backdrop-filter */
    isolation: isolate;              /* crea un contesto senza effetti collaterali */
}

/* Esempio del problema classico */
.header { position: relative; z-index: 1; }
.main   { position: relative; z-index: 2; }

.header .menu-dropdown {
    position: absolute;
    z-index: 9999;   /* Resta comunque SOTTO .main: è chiuso nel contesto di .header (z-index 1) */
}
Consiglio: definisci pochi livelli con nomi chiari (es. variabili --z-dropdown: 100; --z-modal: 1000;) invece di numeri a caso come 9999. Se un elemento "non va sopra", cerca quale antenato ha creato un nuovo contesto.

Flexbox

Flexbox è un sistema di layout unidimensionale (riga o colonna) per distribuire spazio tra elementi.

Proprietà del Contenitore (Container)

.container {
    display: flex;
    
    /* Direzione */
    flex-direction: row;           /* Default: da sinistra a destra */
    flex-direction: row-reverse;   /* Da destra a sinistra */
    flex-direction: column;        /* Dall'alto al basso */
    flex-direction: column-reverse; /* Dal basso all'alto */
    
    /* Wrap (a capo) */
    flex-wrap: nowrap;    /* Default: tutto su una linea */
    flex-wrap: wrap;      /* Va a capo se necessario */
    flex-wrap: wrap-reverse;
    
    /* Allineamento principale (asse principale) */
    justify-content: flex-start;   /* Inizio (default) */
    justify-content: flex-end;     /* Fine */
    justify-content: center;       /* Centro */
    justify-content: space-between; /* Spazio tra gli elementi */
    justify-content: space-around;  /* Spazio intorno agli elementi */
    justify-content: space-evenly;  /* Spazio uniforme */
    
    /* Allineamento trasversale (asse secondario) */
    align-items: stretch;      /* Allunga (default) */
    align-items: flex-start;   /* Inizio */
    align-items: flex-end;     /* Fine */
    align-items: center;       /* Centro */
    align-items: baseline;     /* Allineato alla baseline del testo */
    
    /* Allineamento righe multiple */
    align-content: flex-start;
    align-content: center;
    align-content: space-between;
    
    /* Gap tra elementi */
    gap: 20px;              /* Spazio tra tutti gli elementi */
    row-gap: 20px;          /* Spazio tra righe */
    column-gap: 10px;       /* Spazio tra colonne */
}

Proprietà degli Elementi (Items)

.item {
    /* Crescita */
    flex-grow: 1;      /* Quanto l'elemento può crescere */
    
    /* Riduzione */
    flex-shrink: 1;    /* Quanto l'elemento può ridursi */
    
    /* Dimensione base */
    flex-basis: 200px; /* Dimensione iniziale */
    
    /* Shorthand */
    flex: 1;           /* grow shrink basis */
    flex: 1 1 200px;
    
    /* Ordine */
    order: 2;          /* Cambia l'ordine visivo */
    
    /* Allineamento individuale */
    align-self: center; /* Sovrascrive align-items del container */
}

CSS Grid

CSS Grid è un sistema di layout bidimensionale per righe e colonne.

.container {
    display: grid;
    
    /* Definire colonne */
    grid-template-columns: 200px 200px 200px;     /* 3 colonne fisse */
    grid-template-columns: 1fr 1fr 1fr;          /* 3 colonne uguali */
    grid-template-columns: 1fr 2fr 1fr;          /* Colonna centrale doppia */
    grid-template-columns: repeat(3, 1fr);       /* 3 colonne uguali (shorthand) */
    grid-template-columns: repeat(auto-fit, minmax(200px, 1fr)); /* Responsive */
    
    /* Definire righe */
    grid-template-rows: 100px 200px auto;
    grid-template-rows: repeat(3, 100px);
    
    /* Gap (spazio tra celle) */
    gap: 20px;              /* Tra righe e colonne */
    row-gap: 20px;          /* Tra righe */
    column-gap: 10px;       /* Tra colonne */
    
    /* Allineamento */
    justify-items: start | center | end | stretch;
    align-items: start | center | end | stretch;
    justify-content: start | center | end | space-between;
    align-content: start | center | end | space-between;
}

/* Posizionare singoli elementi */
.item {
    grid-column: 1 / 3;      /* Dalla colonna 1 alla 3 */
    grid-column: span 2;     /* Occupa 2 colonne */
    grid-row: 1 / 3;         /* Dalla riga 1 alla 3 */
    
    /* Shorthand */
    grid-area: 1 / 1 / 3 / 3; /* row-start / col-start / row-end / col-end */
}

Aree Nominate (grid-template-areas)

Il modo più visivo di costruire un layout: si "disegna" la griglia con dei nomi, poi si assegna ogni elemento alla sua area. Ogni stringa è una riga, ogni parola una colonna; il punto . indica una cella vuota.

.pagina {
    display: grid;
    grid-template-columns: 250px 1fr;
    grid-template-rows: auto 1fr auto;
    grid-template-areas:
        "header  header"
        "sidebar main"
        "footer  footer";
    gap: 1rem;
    min-height: 100dvh;
}

.pagina header { grid-area: header; }
.pagina aside  { grid-area: sidebar; }
.pagina main   { grid-area: main; }
.pagina footer { grid-area: footer; }

/* Su mobile basta ridisegnare la mappa: l'HTML non cambia */
@media (max-width: 768px) {
    .pagina {
        grid-template-columns: 1fr;
        grid-template-areas:
            "header"
            "main"
            "sidebar"
            "footer";
    }
}

Colori

CSS supporta vari modi per definire i colori:

.elemento {
    /* Nomi colori predefiniti */
    color: red;
    color: blue;
    color: transparent;
    
    /* Esadecimale */
    color: #FF0000;        /* Rosso */
    color: #00F;           /* Blu (shorthand) */
    
    /* RGB */
    color: rgb(255, 0, 0);           /* Rosso */
    color: rgba(255, 0, 0, 0.5);     /* Rosso semi-trasparente */
    
    /* HSL (Hue, Saturation, Lightness) */
    color: hsl(0, 100%, 50%);        /* Rosso */
    color: hsla(0, 100%, 50%, 0.5);  /* Rosso semi-trasparente */
    
    /* Colori per testo e sfondo */
    color: #333;                     /* Colore testo */
    background-color: #f0f0f0;       /* Colore sfondo */
    
    /* Opacità */
    opacity: 0.5;                    /* 0 (trasparente) a 1 (opaco) */
}

Variabili CSS (Custom Properties)

Le variabili CSS permettono di dare un nome a un valore (un colore, una spaziatura, un font) e riusarlo ovunque. Cambiando la variabile in un solo punto, cambia tutto il sito. Sono la base dei design token e dei temi chiaro/scuro.

Dichiarare e usare

/* Si dichiarano con due trattini, di solito su :root (= l'elemento html) */
:root {
    --colore-primario: #6f42c1;
    --colore-testo: #222;
    --spazio: 1rem;
    --raggio: 0.5rem;
    --font-titoli: 'Playfair Display', serif;
}

/* Si leggono con var() */
.bottone {
    background: var(--colore-primario);
    padding: var(--spazio) calc(var(--spazio) * 2);
    border-radius: var(--raggio);
}

h1, h2 {
    font-family: var(--font-titoli);
}

/* Valore di riserva (fallback) se la variabile non esiste */
.box {
    color: var(--colore-accento, orange);
}

Le variabili seguono la cascata

A differenza delle variabili di SASS, quelle CSS sono "vive" nel browser: si ereditano e si possono ridefinire in un contesto più piccolo. Così si creano varianti di un componente senza riscriverlo.

.bottone {
    --bg: var(--colore-primario);
    background: var(--bg);
    color: white;
}

/* La variante cambia solo la variabile */
.bottone--pericolo { --bg: #dc3545; }
.bottone--successo { --bg: #198754; }
Esempio - un solo componente, tre varianti:
--bg: #6f42c1 --bg: #dc3545 --bg: #198754

Tema chiaro / scuro

È esattamente il meccanismo usato da questo manuale (prova il bottone in basso a destra): i componenti usano solo variabili, e il tema scuro le ridefinisce.

:root {
    --bg-color: #ffffff;
    --text-color: #212529;
}

/* Tema scuro scelto dall'utente con un bottone (data-theme sull'html) */
:root[data-theme="dark"] {
    --bg-color: #1a1a1a;
    --text-color: #e0e0e0;
}

/* Oppure automatico, in base alle impostazioni del sistema operativo */
@media (prefers-color-scheme: dark) {
    :root {
        --bg-color: #1a1a1a;
        --text-color: #e0e0e0;
    }
}

body {
    background-color: var(--bg-color);
    color: var(--text-color);
}

Modificarle con JavaScript

// Leggere
const primario = getComputedStyle(document.documentElement)
    .getPropertyValue('--colore-primario');

// Scrivere: tutti gli elementi che usano la variabile si aggiornano
document.documentElement.style.setProperty('--colore-primario', '#e83e8c');
Best Practice: raccogli in :root i valori ricorrenti del progetto (colori, font, spaziature, raggi, ombre) con nomi che descrivono il ruolo (--colore-primario) e non il valore (--viola): se domani il primario diventa verde, il nome resta corretto.

Testi e Tipografia

.testo {
    /* Font */
    font-family: Arial, Helvetica, sans-serif;  /* Lista fallback */
    font-family: 'Times New Roman', serif;
    font-family: 'Courier New', monospace;
    
    /* Dimensione */
    font-size: 16px;        /* Pixel */

Font Locali con @font-face

Per usare un font acquistato o scaricato (o per non dipendere da Google), si carica il file direttamente dal proprio sito. Il formato da usare è WOFF2: compresso e supportato da tutti i browser moderni.

@font-face {
    font-family: 'Mio Font';                 /* Nome a scelta, da usare poi in font-family */
    src: url('../fonts/mio-font-regular.woff2') format('woff2');
    font-weight: 400;
    font-style: normal;
    font-display: swap;   /* Mostra subito un font di sistema, poi lo sostituisce */
}

@font-face {
    font-family: 'Mio Font';                 /* Stesso nome, peso diverso */
    src: url('../fonts/mio-font-bold.woff2') format('woff2');
    font-weight: 700;
    font-style: normal;
    font-display: swap;
}

body { font-family: 'Mio Font', system-ui, sans-serif; }
strong { font-weight: 700; }  /* Il browser userà automaticamente il file bold */

Font Variabili

Un font variabile contiene in un solo file tutti i pesi (e a volte larghezze, inclinazioni...). Meno file da scaricare e pesi intermedi come 450 o 650.

@font-face {
    font-family: 'Inter';
    src: url('../fonts/Inter-Variable.woff2') format('woff2');
    font-weight: 100 900;    /* Intervallo di pesi disponibili */
    font-display: swap;
}

h1 { font-weight: 750; }     /* Qualsiasi valore nell'intervallo */

/* Assi personalizzati del font (dipendono dal font scelto) */
.titolo-largo {
    font-variation-settings: "wdth" 125;
}

Stili per Liste

Le liste (<ul>, <ol>) hanno uno stile di default: un marcatore (pallino o numero) e un rientro a sinistra (circa 40px di padding-left). Con poche proprietà si possono cambiare entrambi, oppure azzerarli per costruire menu e navigazioni.

Il tipo di marcatore: list-style-type

ul {
    list-style-type: disc;      /* ● pallino pieno (default di ul) */
    list-style-type: circle;    /* ○ cerchio vuoto */
    list-style-type: square;    /* ■ quadratino */
    list-style-type: none;      /* nessun marcatore */
    list-style-type: "→ ";      /* qualsiasi stringa (anche un'emoji) */
}

ol {
    list-style-type: decimal;              /* 1. 2. 3. (default di ol) */
    list-style-type: decimal-leading-zero; /* 01. 02. 03. */
    list-style-type: lower-alpha;          /* a. b. c. */
    list-style-type: upper-alpha;          /* A. B. C. */
    list-style-type: lower-roman;          /* i. ii. iii. */
    list-style-type: upper-roman;          /* I. II. III. */
}

Posizione, immagine e shorthand

ul {
    /* Dove sta il marcatore rispetto al testo */
    list-style-position: outside;  /* Default: fuori dal box, il testo a capo resta allineato */
    list-style-position: inside;   /* Dentro il box: il testo a capo va sotto il marcatore */

    /* Un'immagine come marcatore (poco controllabile: meglio ::marker o ::before) */
    list-style-image: url('img/freccia.svg');

    list-style: square inside;
    list-style: none;              /* Il più usato in assoluto */

Azzerare una lista (per menu e navigazioni)

Quasi ogni menu di navigazione è una <ul>: semanticamente è una lista di link. Per usarla come menu si tolgono marcatori e rientro, poi si dispone in orizzontale con Flexbox.

.menu {
    list-style: none;   /* Via i pallini */
    margin: 0;          /* Via il margine sopra/sotto */
    padding: 0;         /* Via il rientro a sinistra (il "buco" di 40px) */

    display: flex;      /* Voci in orizzontale */
    gap: 1.5rem;
}

.menu a {
    text-decoration: none;
}

Personalizzare il marcatore: ::marker

Lo pseudo-elemento ::marker seleziona direttamente il pallino o il numero: si possono cambiare colore, dimensione, font e perfino il contenuto, senza toccare il testo.

li::marker {
    color: #e83e8c;
    font-size: 1.2em;
    font-weight: bold;
}

/* Cambiare il contenuto del marcatore */
.lista-check li::marker {
    content: "✓  ";
    color: #198754;
}

Marcatore totalmente libero: ::before

::marker accetta poche proprietà (niente sfondi, bordi o posizionamento). Per un marcatore "disegnato" si toglie quello originale e se ne crea uno con ::before.

.lista-pallini {
    list-style: none;
    padding: 0;
}

.lista-pallini li {
    position: relative;
    padding-left: 1.5rem;   /* Spazio per il marcatore */
    margin-bottom: 0.5rem;
}

.lista-pallini li::before {
    content: "";             /* Obbligatorio, anche se vuoto */
    position: absolute;
    left: 0;
    top: 0.45em;
    width: 0.6rem;
    height: 0.6rem;
    border-radius: 50%;
    background: linear-gradient(135deg, #0d6efd, #e83e8c);
}

Trasformazioni (Transform)

La proprietà transform permette di modificare la forma e la posizione degli elementi senza alterare il flusso del documento. È fondamentale per creare effetti interattivi e animazioni.

Trasformazioni 2D

Translate (Spostamento)

Sposta l'elemento lungo l'asse X e Y.

transform: translate(50px, 20px);
/* o singolarmente */
transform: translateX(50px);
transform: translateY(20px);
Rotate (Rotazione)

Ruota l'elemento in senso orario (valori positivi) o antiorario.

transform: rotate(45deg);
transform: rotate(-90deg);
transform: rotate(0.5turn); /* 180deg */
Scale (Ridimensionamento)

Ingrandisce (>1) o rimpicciolisce (<1) l'elemento.

transform: scale(1.5); /* 150% */
transform: scale(0.5); /* 50% */
transform: scale(2, 1); /* solo larghezza */
Skew (Inclinazione)

Inclina l'elemento lungo gli assi.

transform: skew(15deg, 10deg);
transform: skewX(20deg);

Trasformazioni 3D e Prospettiva

Per attivare l'effetto 3D realistico, è necessario definire la perspective sul genitore.

.container-3d {
    perspective: 1000px; /* Punto di fuga */
}

.box-3d {
    transform: rotateX(45deg) rotateY(45deg);
    transform-style: preserve-3d; /* Per figli 3D */
}

Origine della Trasformazione

Di default le trasformazioni avvengono dal centro (50% 50%). Puoi cambiarlo con transform-origin.

.elemento {
    transform-origin: top left; /* o 0% 0% */
    transform-origin: bottom right;
    transform: rotate(45deg); /* Ruota attorno all'angolo */
}

Transizioni e Animazioni

Transizioni

Le transizioni animano il cambiamento di proprietà CSS:

.box {
    background: blue;
    transition: background 0.3s ease;
    /* proprietà durata timing-function delay */
}

.box:hover {
    background: red;  /* Transizione animata */
}

/* Transizioni multiple */
.box {
    transition: background 0.3s ease,
                transform 0.5s ease-in-out,
                opacity 0.2s linear;
}

/* Transizione su tutto */
.box {
    transition: all 0.3s ease;
}

/* Timing functions */
.box {
    transition-timing-function: ease;        /* Default */
    transition-timing-function: linear;      /* Velocità costante */
    transition-timing-function: ease-in;     /* Accelera */
    transition-timing-function: ease-out;    /* Decelera */
    transition-timing-function: ease-in-out; /* Accelera e decelera */
    transition-timing-function: cubic-bezier(0.1, 0.7, 1.0, 0.1); /* Custom */
}

Animazioni Keyframe

/* Definire l'animazione */
@keyframes slideIn {
    from {
        transform: translateX(-100%);
        opacity: 0;
    }
    to {
        transform: translateX(0);
        opacity: 1;
    }
}

/* Con step intermedi */
@keyframes pulse {
    0% {
        transform: scale(1);
    }
    50% {
        transform: scale(1.1);
    }
    100% {
        transform: scale(1);
    }
}

/* Applicare l'animazione */
.elemento {
    animation: slideIn 1s ease-out;
    /* nome durata timing-function delay iteration-count direction fill-mode */
    
    animation-name: slideIn;
    animation-duration: 1s;
    animation-timing-function: ease-out;
    animation-delay: 0.5s;
    animation-iteration-count: infinite;  /* o un numero */
    animation-direction: normal;          /* normal | reverse | alternate */
    animation-fill-mode: forwards;        /* none | forwards | backwards | both */
    animation-play-state: running;        /* running | paused */
}

/* Animazione al hover */
.elemento:hover {
    animation: pulse 0.5s infinite;
}

Media Queries (Responsive Design)

Le media queries permettono di applicare stili diversi in base alle caratteristiche del dispositivo:

/* Mobile First Approach (Consigliato) */
/* Stili base per mobile */
.container {
    width: 100%;
    padding: 15px;
}

/* Tablet e oltre (min-width: da questa dimensione in su) */
@media (min-width: 768px) {
    .container {
        width: 750px;
        padding: 20px;
    }
}

/* Desktop (min-width: 1024px) */
@media (min-width: 1024px) {
    .container {
        width: 1000px;
    }
}

/* Desktop Large */
@media (min-width: 1200px) {
    .container {
        width: 1140px;
    }
}

/* Desktop Approach (max-width: fino a questa dimensione) */
@media (max-width: 1200px) {
    /* Stili per schermi fino a 1200px */
}

@media (max-width: 768px) {
    /* Stili per tablet e smartphone */
    .menu {
        flex-direction: column;
    }
}

@media (max-width: 480px) {
    /* Stili solo per smartphone */
    .box {
        width: 100%;
    }
}

/* Range di dimensioni */
@media (min-width: 768px) and (max-width: 1024px) {
    /* Solo per tablet */
}

/* Orientamento */
@media (orientation: portrait) {
    /* Modalità verticale */
}

@media (orientation: landscape) {
    /* Modalità orizzontale */
}

/* Tipo di media */
@media print {
    /* Stili per la stampa */
    .no-print {
        display: none;
    }
}

@media screen {
    /* Solo per schermi */
}

/* Retina display */
@media (-webkit-min-device-pixel-ratio: 2), (min-resolution: 192dpi) {
    /* Schermi ad alta densità */
}

/* Preferenze utente */
@media (prefers-color-scheme: dark) {
    /* Dark mode */
    body {
        background: #1a1a1a;
        color: #ffffff;
    }
}

@media (prefers-reduced-motion: reduce) {
    /* Ridurre animazioni per accessibilità */
    * {
        animation: none !important;
        transition: none !important;
    }
}
