Un gradiente è un'immagine

Un gradiente CSS è una sfumatura tra due o più colori generata dal browser. La cosa più importante da sapere: per il CSS un gradiente non è un colore, è un'immagine. Quindi:

  • va in background-image (o nello shorthand background), non in background-color;
  • funziona dovunque si accetti un'immagine: border-image, mask-image, list-style-image...;
  • si possono sovrapporre più gradienti e immagini, separati da virgole;
  • non pesa nulla da scaricare e resta nitido a qualsiasi risoluzione.
.box {
    background-color: #667eea;  /* Colore di riserva (fallback) */
    background-image: linear-gradient(135deg, #667eea, #764ba2);
}

/* ❌ Non funziona: un gradiente non è un colore */
.box { background-color: linear-gradient(#667eea, #764ba2); }

Approfondimento ispirato a A Complete Guide to CSS Gradients di CSS-Tricks.

linear-gradient: sfumatura lungo una linea

La sintassi è linear-gradient(direzione, colore1, colore2, ...). La direzione è facoltativa (default: dall'alto verso il basso) e si scrive con parole chiave o con un angolo.

background: linear-gradient(#0d6efd, #e83e8c);            /* ↓ default: to bottom */
background: linear-gradient(to right, #0d6efd, #e83e8c);   /* → */
background: linear-gradient(to top left, #0d6efd, #e83e8c);/* ↖ verso l'angolo */
background: linear-gradient(45deg, #0d6efd, #e83e8c);      /* angolo */
background: linear-gradient(90deg, red, orange, yellow, green, blue); /* più colori */

Come funzionano gli angoli

Pensa a un orologio: 0deg punta in alto (equivale a to top), 90deg a destra, 180deg in basso, 270deg a sinistra. L'angolo indica verso dove va la sfumatura, cioè dove si trova l'ultimo colore. Attenzione: to top right e 45deg coincidono solo in un box quadrato; con le parole chiave l'ultimo colore arriva sempre esattamente nell'angolo.

Color stop e tagli netti

Di default i colori sono distribuiti in modo uniforme. Aggiungendo una posizione dopo ogni colore (color stop) decidi tu dove si trovano.

/* Il rosa arriva subito, al 20% */
background: linear-gradient(to right, #0d6efd, #e83e8c 20%, #fd7e14);

/* Hint: sposta il punto a metà della sfumatura */
background: linear-gradient(to right, #0d6efd, 80%, #e83e8c);

/* Due posizioni per lo stesso colore = fascia piena */
background: linear-gradient(to right, #0d6efd 0 30%, #e83e8c 70% 100%);

Tagli netti (hard stop)

Se un colore finisce esattamente dove inizia il successivo, non c'è spazio per sfumare: ottieni un bordo netto. È la base di strisce, bandiere e pattern.

/* Bandiera italiana: tre fasce nette */
.bandiera {
    background: linear-gradient(to right,
        #009246 0 33.33%,
        #ffffff 33.33% 66.66%,
        #ce2b37 66.66% 100%);
}

/* Metà e metà in diagonale */
.diagonale {
    background: linear-gradient(135deg, #0d6efd 50%, #ffc107 50%);
}

radial-gradient: sfumatura dal centro verso l'esterno

Parte da un punto e si allarga a cerchio o ellisse. Prima della virgola puoi indicare forma, dimensione e posizione (dopo at).

background: radial-gradient(#ffc107, #e83e8c);                  /* ellisse, al centro */
background: radial-gradient(circle, #ffc107, #e83e8c);          /* cerchio */
background: radial-gradient(circle at top left, #ffc107, #e83e8c); /* centro spostato */
background: radial-gradient(circle at 70% 30%, #fff 0 10%, transparent 11%), #0d6efd;
background: radial-gradient(circle closest-side, #ffc107, #e83e8c); /* finisce al lato più vicino */

Parole chiave per la dimensione: closest-side, closest-corner, farthest-side, farthest-corner (default). Un uso classico è la vignettatura: radial-gradient(transparent 50%, rgba(0,0,0,0.6)) sopra una foto.

conic-gradient: sfumatura che gira intorno a un punto

I colori ruotano attorno al centro, come le lancette di un orologio. Con i tagli netti diventa un grafico a torta fatto solo di CSS.

/* Ruota dei colori */
background: conic-gradient(red, yellow, lime, cyan, blue, magenta, red);

/* Grafico a torta: 40% / 35% / 25% */
.torta {
    border-radius: 50%;
    background: conic-gradient(
        #0d6efd 0 40%,
        #e83e8c 40% 75%,
        #ffc107 75% 100%);
}

/* Punto di partenza e centro personalizzati */
background: conic-gradient(from 90deg at 30% 50%, #0d6efd, #e83e8c);

Gradienti ripetuti e pattern

repeating-linear-gradient, repeating-radial-gradient e repeating-conic-gradient ripetono all'infinito la sequenza di color stop. Con i tagli netti creano pattern senza nessuna immagine.

/* Strisce diagonali (nastro "lavori in corso") */
.strisce {
    background: repeating-linear-gradient(45deg,
        #ffc107 0 20px,
        #212529 20px 40px);
}

/* Cerchi concentrici */
.bersaglio {
    background: repeating-radial-gradient(circle,
        #dc3545 0 15px, #fff 15px 30px);
}

/* Scacchiera: un conico ripetuto ogni 40px */
.scacchiera {
    background: repeating-conic-gradient(#212529 0 25%, #f8f9fa 0 50%)
                0 0 / 40px 40px;
}

/* Carta a righe: background-size ripete il gradiente */
.quaderno {
    background: linear-gradient(transparent 27px, #9ec5fe 27px 28px) 0 0 / 100% 28px,
                #fff;
}

Più livelli e overlay su immagini

Nella proprietà background puoi elencare più livelli separati da virgole: il primo è quello più in alto. Il caso più utile in assoluto è il velo scuro sopra una foto, per rendere leggibile il testo bianco.

.hero {
    background:
        /* 1° livello (sopra): sfuma dal nero a trasparente */
        linear-gradient(to top, rgba(0,0,0,0.8), transparent 60%),
        /* 2° livello (sotto): la foto */
        url('img/montagne.jpg') center / cover;
    color: #fff;
}
Monti Sibillini
Testo leggibile grazie al gradiente
Contrasto: il testo su un gradiente deve rispettare il contrasto minimo (4.5:1) nel punto peggiore, cioè dove lo sfondo è più chiaro sotto il testo. Vedi Colore e Contrasto.

Effetti creativi

Testo sfumato

Il gradiente è lo sfondo dell'elemento; background-clip: text lo "ritaglia" sulla forma delle lettere, e il colore trasparente lo lascia vedere.

.titolo-sfumato {
    background: linear-gradient(90deg, #0d6efd, #e83e8c, #fd7e14);
    -webkit-background-clip: text;
    background-clip: text;
    color: transparent;
}

Web Design

Bordo sfumato (anche con angoli arrotondati)

border-image accetta un gradiente ma ignora border-radius. Il trucco: due sfondi, uno pieno limitato al padding-box e il gradiente esteso fino al border-box, con un bordo trasparente che lo lascia intravedere.

.card-bordo {
    border: 4px solid transparent;
    border-radius: 1rem;
    background:
        linear-gradient(white, white) padding-box,           /* riempimento interno */
        linear-gradient(135deg, #0d6efd, #e83e8c) border-box; /* visibile solo nel bordo */
}

Gradiente animato

I colori di un gradiente non si possono animare direttamente con transition, ma si può rendere lo sfondo più grande del box e spostarlo con background-position.

.animato {
    background: linear-gradient(270deg, #0d6efd, #e83e8c, #fd7e14, #0d6efd);
    background-size: 300% 100%;
    animation: scorri 8s linear infinite;
}
@keyframes scorri {
    from { background-position: 0% 50%; }
    to   { background-position: 300% 50%; }
}
@media (prefers-reduced-motion: reduce) {
    .animato { animation: none; }
}

Dissolvenza verso il trasparente

Per far "sparire" un contenuto lungo (es. "Leggi tutto") si usa un gradiente come maschera: le parti nere restano visibili, quelle trasparenti spariscono.

.anteprima {
    max-height: 8rem;
    overflow: hidden;
    mask-image: linear-gradient(to bottom, black 50%, transparent);
}

Sfumature più belle: evitare la "zona grigia"

Sfumando tra due colori complementari (es. blu e giallo) il centro diventa spesso grigiastro e spento. Succede perché il browser calcola i colori intermedi nello spazio colore sRGB, che non corrisponde a come l'occhio percepisce i colori. Il CSS moderno permette di scegliere lo spazio colore in cui interpolare:

background: linear-gradient(to right, blue, yellow);              /* sRGB: centro grigio */
background: linear-gradient(to right in oklab, blue, yellow);     /* percettivo: più pulito */
background: linear-gradient(to right in oklch, blue, yellow);     /* passa per la ruota dei colori */

in oklab
in oklch

Nei browser che non supportano la sintassi in ... la regola viene ignorata: dichiara prima una versione classica come fallback. Per oklch vedi CSS Moderno → Colore. In alternativa funziona sempre il trucco "a mano": aggiungere un colore intermedio vivace (es. blue, #00b4d8, yellow).
